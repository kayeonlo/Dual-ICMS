# Dual-ICMS

This repository contains the source code and processed data associated with the manuscript:

**Single-Cell and Population-Level Neuromodulation Dynamics in Dual-Electrode Intracortical Stimulation**

Kayeon Kim *et al.*  
https://doi.org/10.1101/2025.06.25.661479

## Overview

This repository provides the code and processed datasets used to generate the main and supplementary figures in the manuscript, including:

- MATLAB analysis scripts to generate main and supplementary figures (runs in Matlab R2022a)
- Processed calcium imaging data
- Processed ROI fluorescence traces
- Computational modeling (python script; https://github.com/kayeonlo/Dual-ICMS-visual-cortex)
- Deep learning analyses
- Source data for figures
- Processed calcium imaging data
- Processed ROI fluorescence traces

The repository is intended to facilitate reproducibility of the analyses presented in the manuscript.
